🐛 TROUBLESHOOTING
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Issue: "Database not found"
→ Check paths: ls -lh ./large_db_mode_30k
→ Build first: python build_large_retrieval_database.py ...

Issue: "Gradio not installed"
→ pip install gradio

Issue: "Port already in use"
→ Use different port: --port 8080
→ Or kill process: pkill -f gradio

Issue: "Images not loading"
→ Check image paths in database
→ Ensure images still exist

Issue: "Slow retrieval"
→ Ensure FAISS is enabled (--use_faiss during build)
→ Use GPU: --device cuda
→ Reduce top_k: Select fewer results

Issue: "Share link not working"
→ Check internet connection
→ Try again (gradio servers sometimes busy)
→ Use ngrok as alternative
