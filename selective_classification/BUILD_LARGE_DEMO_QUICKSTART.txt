✅ WHAT THIS DOES
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Automatically builds 3 databases with checkpoints:
  ✓ MODE (30K samples)    - Your trained MODE model
  ✓ Random (30K samples)  - Baseline comparison
  ✓ Full (100K samples)   - Upper bound

Features:
  ✓ Checkpointing - Resume if interrupted
  ✓ Verification - Checks all databases
  ✓ Auto-launcher - One-click demo start
  ✓ Documentation - README included


🚀 SUPER QUICK START (1 COMMAND)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

# 2. Build MODE database (30K)
# 3. Build Random database (30K)
# 4. Build Full database (100K)
# 5. Verify everything ✓

🐛 TROUBLESHOOTING
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Problem: "Data directory not found"
Solution:
  → Check path: ls datacomp_data/
  → Specify: ./build_demo_pipeline.sh --data_dir /correct/path

Problem: "MODE indices not found"
Solution:
  → Run MODE selection first
  → Or script will skip MODE database (still builds Random & Full)

Problem: "Out of memory"
Solution:
  → Reduce batch size: Edit build_large_retrieval_database.py
  → Or use CPU: Will be slower but works

Problem: "Build interrupted"
Solution:
  → Resume: ./build_demo_pipeline.sh --resume
  → Script automatically continues from last checkpoint!

Problem: "FAISS not installed"
Solution:
  → Optional but recommended: pip install faiss-gpu
  → Or pip install faiss-cpu
  → Or continue without (slower retrieval)

Problem: "Disk full"
Solution:
  → Need ~10GB free
  → Or reduce samples: --mode_samples 10000 --full_samples 30000

1. Run Overnight

   Perfect to start before leaving!

2. Use screen/tmux
   screen -S demo_build
   ./build_demo_pipeline.sh
   # Detach: Ctrl+A, D
   # Reattach later: screen -r demo_build

3. Check Progress
   tail -f demo_databases/build_progress.json

4. Test Early
   After MODE database builds, try:
   python gradio_demo_largescale.py --mode_db ./demo_databases/mode_30k

5. Build Smaller First
   Test with small sizes:
   ./build_demo_pipeline.sh \
       --mode_samples 1000 \
       --random_samples 1000 \
       --full_samples 3000
   
   Takes ~10 minutes, good for testing!
