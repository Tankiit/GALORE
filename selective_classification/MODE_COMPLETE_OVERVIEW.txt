🔧 ARCHITECTURE DETAILS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

MODEHypernetwork:
  Input:  Binary State [20 dims]
  Hidden: 128 dims, 3 layers
  Output: Strategy Weights [7 dims]

  Strategies:
    [0] alignment_quality     - High CLIP similarity
    [1] alignment_difficulty  - Hard samples
    [2] visual_complexity     - Complex images
    [3] text_richness         - Descriptive text
    [4] cross_modal_diversity - Diverse pairs
    [5] balanced              - Uniform
    [6] uncertainty           - High uncertainty

SimpleMODEScorer:
  Input:  Binary Features [12 dims]
  Hidden: 128 dims, 3 layers
  Output: Importance Score [1 dim]

Binary State Encoding (20 bits):
  Bits 0-1:   Vision loss trend
  Bits 2-3:   Text loss trend
  Bits 4-5:   Alignment loss trend
  Bits 6-7:   Gradient norm
  Bits 8-9:   Training phase
  Bits 10-11: Modality balance
  Bits 12-13: Learning rate
  Bits 14-15: Stability
  Bits 16-17: Data efficiency
  Bits 18-19: Generalization gap

✨ KEY INSIGHTS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. MODE learns easy-to-hard curriculum automatically
   Early: alignment_quality (0.35) → easy, well-aligned samples
   Late:  alignment_difficulty (0.30) → hard, challenging samples

2. Hypernetwork adapts based on training state
   Uses 20-bit binary encoding of training metrics
   Outputs 7 strategy weights that evolve over time

3. Data efficiency through smart selection
   30% of data → 96.7% of performance
   Saves compute, time, and money

4. Generalizes to multiple tasks
   ImageNet classification (zero-shot)
   COCO retrieval (I2T and T2I)
   Shows learned representations transfer well
