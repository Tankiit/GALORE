🚀 QUICK START (3 STEPS)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Step 1: Install Dependencies
────────────────────────────
pip install transformers torch gradio matplotlib pillow


Step 2: Build Database
──────────────────────
python build_retrieval_database.py \
    --data_dir ./datacomp_data \
    --model_path ./mode_output/final_clip_model.pt \
    --output_path ./retrieval_database.pt \
    --max_samples 1000

This takes ~5 minutes for 1000 samples.


Step 3: Launch Demo
───────────────────
python interactive_retrieval_demo.py \
    --interface web \
    --database_path ./retrieval_database.pt \
    --model_path ./mode_output/final_clip_model.pt

Then open: http://localhost:7860

📈 UNDERSTANDING SCORES
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Similarity scores range from 0.0 to 1.0:

  Score > 0.80:  Excellent match! 🟢
  Score > 0.65:  Good match       🟡
  Score > 0.50:  Fair match       🟠
  Score < 0.50:  Weak match       🔴

Example:
  Text: "a cat sitting on a windowsill"
    → Image #1 [0.89]: Cat on windowsill ✓ Perfect!
    → Image #2 [0.82]: Cat indoors       ✓ Good
    → Image #3 [0.75]: Cat near window   ✓ Reasonable
    → Image #4 [0.54]: Dog on windowsill ✗ Wrong animal

🐛 TROUBLESHOOTING
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Issue: "No database loaded"
→ Build database first: python build_retrieval_database.py

Issue: "gradio not installed"
→ Install: pip install gradio
→ Or use CLI: --interface cli

Issue: "Model not found"
→ Check path: --model_path ./mode_output/final_clip_model.pt
→ Or use pretrained: omit --model_path

Issue: Slow retrieval
→ Pre-compute embeddings with build_retrieval_database.py
→ Use GPU: --device cuda
→ Reduce samples: --max_samples 500

✨ COMPARISON: MODE vs RANDOM
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Build two databases and compare:

# MODE-selected data (better diversity)
python build_retrieval_database.py \
    --selected_indices ./datacomp_mode_cache/selected_indices.pt \
    --model_path ./mode_output/final_clip_model.pt \
    --output_path ./db_mode.pt

# Random data (baseline)
python build_retrieval_database.py \
    --data_dir ./datacomp_data \
    --model_path ./random_baseline/final_clip_model.pt \
    --output_path ./db_random.pt

# Compare side-by-side!
# Launch two demos on different ports:
python interactive_retrieval_demo.py --database_path ./db_mode.pt --port 7860
python interactive_retrieval_demo.py --database_path ./db_random.pt --port 7861

Try same query on both → See which retrieves better!


🎓 TIPS FOR BEST RESULTS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. Use descriptive queries:
   ✓ "a golden retriever playing fetch in a park"
   ✗ "dog"

2. Be specific:
   ✓ "sunset over ocean with pink clouds"
   ✗ "pretty picture"

3. Try variations:
   • "happy person" vs "smiling person" vs "joyful person"
   • Compare which works best

4. Use MODE-selected data:
   • More diverse samples
   • Better coverage of visual concepts

5. Fine-tune for your domain:
   • Train on domain-specific data
   • Better domain retrieval
